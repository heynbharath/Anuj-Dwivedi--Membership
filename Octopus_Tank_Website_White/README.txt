OCTOPUS TANK 2026 - WEBSITE (white theme)

Open index.html in a browser, or upload this whole folder to any static host (Vercel, Netlify, GitHub Pages).

WHATSAPP NUMBER
Open index.html, search for  var WA_NUMBER=""  and put the number inside the quotes,
country code first, digits only. Example: "919876543210". Every WhatsApp button
(nav, hero, FAQ, closing panel, floating button, footer) updates from that one line.
Until it is set, the buttons open WhatsApp without a number.

REGISTRATION FORM
In the same place, find  var FORM_URL=""  and paste your form link (Google Form, Tally, etc.).
The hero, FAQ and closing buttons then turn into "Register your team" links. Until set they
show "Registration opens soon" and stay disabled.
The RSVP fee appears only in the FAQ, and is asked for inside the form.
